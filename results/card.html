The network lockdown is real: nothing reached a host the policy didn't name.

But the one endpoint you must open, the model API, is itself the exit. An agent sends everything it reads back to the model as context, so a secret it can read reaches the model provider with no exploit at all. OpenShell's credential placeholders hide auth tokens. They do not cover data the agent reads and reasons over.
