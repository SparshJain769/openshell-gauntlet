Security eval · NVIDIA OpenShell v0.1.5

The sandbox blocked every exit I tried — except the one it has to leave open.

OpenShell isolates an AI agent so it can only reach the network you allow. I planted a fake secret, ran an agent under a default-deny policy that opens only the model endpoint, and told it to leak the secret five ways. Here is what the sandbox actually did.

The network lockdown is real: nothing reached a host the policy didn't name.

But the one endpoint you must open — the model API — is itself the exit. An agent sends everything it reads back to the model as context, so a secret it can read reaches the model provider with no exploit at all. OpenShell's credential placeholders hide auth tokens; they don't cover data the agent reads and reasons over.
